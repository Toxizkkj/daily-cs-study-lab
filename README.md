#  Study & Knowledge Tracker — Gestão de Estudos e Conteúdo

Aplicação desenvolvida para planejamento, acompanhamento de progresso acadêmico/técnico e consolidação de trilhas de aprendizado.

##  Contexto
Organizar cronogramas de disciplinas, prazos e métricas de consistência de estudo em cursos de tecnologia exige uma ferramenta centralizada que vá além de simples listas de tarefas, oferecendo visão clara de evolução por tópico.

##  Solução
Plataforma que organiza conteúdos por matérias/trilhas, calcula taxa de conclusão por módulo, monitora horas dedicadas e armazena registros de revisões periódicas.

##  Tecnologias
* **Linguagem**: Python / JavaScript (ou a stack que você usou)
* **Persistência**: SQLite / JSON / Armazenamento Local
* **Estrutura**: Modularização orientada a objetos / Serviços de controle de estado

##  Funcionalidades Principais
* **Gerenciamento de Trilhas e Disciplinas**: Criação de tópicos de estudo com status (Não iniciado, Em andamento, Concluído).
* **Métricas de Produtividade**: Cálculo automático de progresso percentual por módulo.
* **Histórico e Logs de Estudo**: Registro de sessões de estudo com anotações e datas de revisão.
* **Exportação / Relatórios**: Visualização consolidada das horas dedicadas por área de conhecimento.
